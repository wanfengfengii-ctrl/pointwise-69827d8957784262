# Bridge strain handoff

这是一个只使用 Python 3.11 标准库和 SQLite 的离线应变录制交班工程。

## 业务流程

1. `RecordingCatalog.register` 登记固定录制号和原位布局。
2. `StripeStore.ingest` 接纳多个条带。每个条带拥有自己的本地槽位到原录制位映射。
3. 条带可以包含具名直接读数和具名 GF(2) 异或校验。缺位不生成直接证据。
4. `seal_package` 按选定条带生成固定包。包内逐条保存原始编号、条带身份、局部槽位、原录制位和右值。
5. `review_package` 对固定包做全量二元消元。全包相容时，只有在全部相容解中唯一的原位才确认，否则保持未知。
6. 每个确认值带源编号凭据。凭据可以从固定包独立回算。
7. 成功结果写入 `ReportStore`，并绑定父包号。冲突或提交失败不生成成功报告。
8. `read_report` 可在重开后按报告号读回原请求、逐位结果和父包关联。

## 输入与计算

录制布局是有序的字符串原位序列。直接读数是单原位等式，异或校验是多个原位的 GF(2) 等式。右值只能是 0 或 1。条带映射按条带自身解释，多个条带可以覆盖同一原位。相同原位在组合中按异或抵消。计算不做单位换算、舍入或插值。相同固定包和相同请求始终得到相同结果。

## 错误语义

- 非法登记、非法槽位、非法证据和值、录制内源编号重号会拒绝本次输入。
- 整批接纳使用 SQLite 事务，失败不会留下半批条带。
- 签发只接受同一录制的已接纳条带。提交失败会回滚候选包，旧包仍可读。
- 未知包号和未知报告号返回查找错误。
- 合法但相互矛盾的证据返回 `conflict`，不生成确认值和成功报告。
- 越界请求和结构非法输入会拒绝复核，不写报告。

## 运行

```text
python3 -m unittest discover -s tests -p test_*.py
python3 demo.py
```

`demo.py` 使用内存数据库完成登记、接纳、封存、离线复核和报告查回，并打印实际结果。
